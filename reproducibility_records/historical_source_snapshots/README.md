# Historical analysis source snapshots

This directory contains three source files preserved byte-for-byte because their SHA-256 digests are cited in historical execution manifests. They document source versions associated with earlier analyses and are provided for provenance and inspection. They are not current supported entry points.

For current analyses, use the scripts in `scripts/primary/`, `scripts/sensitivity/` and `scripts/diagnostics/`. The historical source files retain their original identifiers and comments so that their recorded checksums remain valid.
