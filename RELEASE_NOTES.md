# Version 7 release notes

This documentation-only release corrects two reader-facing errors identified
during the Version 5 review:

- Removed the duplicated article in the README sentence describing the
  undocumented `blood_pressure` codes.
- Corrected the Experiment IX shell example to use standard single-backslash
  line continuations for POSIX-compatible shells.

The primary Experiment VIII script and its generated scientific outputs have
not been modified. No new experiment was run for this release. The recorded
11 November 2026 reproduction evidence remains the basis for the reported
reproduction status.

The author selected the MIT Licence for the repository code and accompanying
reproducibility documentation. Added the standard MIT `LICENSE` file and
updated `CITATION.cff` and the README accordingly. The licence does not cover
the third-party dataset, which is not redistributed. The repository URL and DOI
remain unspecified until the public GitHub/Zenodo deposit is completed.
