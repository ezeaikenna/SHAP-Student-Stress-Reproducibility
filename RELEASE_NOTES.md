# Release information

## Version 1.0.2

This release contains the primary analysis implementation, the
blood-pressure feature-exclusion sensitivity analysis, the broader diagnostic-run reproduction (with a selected supplementary
Decision Tree case-probability output), saved analysis outputs, computational
environment specifications, and execution records.

The execution record identifies and preserves the exact historical primary
script associated with the recorded run under `scripts/archive/`. The current
canonical primary script is provided separately in `scripts/primary/`; both
checksums are recorded in the reproduction manifest.

The code and accompanying reproducibility documentation are released under
the MIT Licence. The licence does not cover the third-party dataset, which is
not redistributed.
