# Retained Decision Tree case-probability output

This directory preserves one selected supplementary output from the broader
diagnostic-run reproduction:

- `decision_tree_test_case_probabilities.csv`: case-level Decision Tree
  predicted probabilities and case-level log-loss values.

The diagnostic script reproduces a broader six-model workflow; it is not a
Decision-Tree-only pipeline. This directory does not contain the complete
output set generated by that workflow.

For this case-level calculation, the diagnostic run clips probabilities
using machine epsilon. The primary analysis uses a 1e-15 lower bound.
Consequently, these case-level log-loss values should be interpreted
separately and should not be substituted for primary-analysis results.
