COMPUTATIONAL ANALYSIS RECORD

Dataset: StressLevelDataset.csv (not redistributed)
Observations: 1,100
Predictors: 20
Target: stress_level
Random seed: 20261009
Train/test split: Stratified 80/20; one fixed held-out test set
Cross-validation: Stratified five-fold on the training partition only
Models: Logistic Regression, RBF-SVM, Random Forest, Extra Trees, MLP, Decision Tree
Input-corruption analysis: 10 independent perturbation repeats at 5%, 10%, and 20%
Bootstrap: 1,000 resamples for held-out macro-F1 confidence intervals
Feature ablation: one predictor removed at a time; each model retrained and evaluated on the same holdout
SHAP stability: common background and fixed explanation sample for the training-CV-selected model;
five repeats per non-zero corruption level; rank correlation, cosine similarity, and top-five overlap
Target-label provenance: not independently verified
External validation: not performed
Clinical validity: not established

The corruption percentages are probabilities under the implemented synthetic
perturbation procedure and are not calibrated real-world measurement-error
magnitudes. Model selection uses training-only cross-validation; held-out test
performance is reported without using the test set for model selection.

Output-generation status is recorded in table_7_output_verification.csv.


PUBLIC ARCHIVE CLARIFICATION
The exact historical primary and diagnostic scripts are retained in scripts/archive/. Their SHA-256 checksums are recorded in reproduction_manifest.json. The diagnostic run is a broad six-model analysis run that additionally exports Decision Tree case-level probabilities; it is not a Decision-Tree-only pipeline. Its case-level log-loss uses machine-epsilon clipping, while the primary run uses a 1e-15 lower bound. The scripts' shap_errors.csv output is a diagnostic record of SHAP computation failures, not a performance table.
