# Computational reproduction record

This directory contains the recorded execution log, computational analysis
record, output-verification table, reference-output comparison, and saved
outputs from the analysis completed on 11 November 2026.

The dataset is not redistributed. Its checksum and the computational
environment are documented in the manifest. The manifest identifies the exact
historical primary script associated with the recorded execution and preserves
that script under `scripts/archive/`, with its SHA-256 checksum. It separately
records the current canonical primary script and its checksum.

The archived-output comparison documents numerical agreement with reference
outputs. This is a reproducibility consistency check, not external validation
of the dataset or its target-label generation procedure.
